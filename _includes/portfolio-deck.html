Kick Avenue · architecture04
Kick Avenue Backend modernisation

Lumen 5.5 → Laravel 12, then a returns engine on top

Live in Production
Problem

A 2017-era Lumen 5.5 monolith ran every money flow. It was hard to test and hard to scale, and it lacked a safe workflow for returns, refunds and relisting.

What I did
  • Upgraded Lumen 5.5 → Laravel 12 / PHP 8.4 behind a test harness I built first
  • Moved to Octane on FrankenPHP; fixed long-running-worker memory leaks
  • Wrapped OpenSearch in a circuit breaker with cached fallbacks
  • Built the returns workflow: QC → relist or refund, idempotent credits, a 1.5× refund ceiling, and the CMS screens for it
What improved
  • Search can fail without taking the API down: OpenSearch sits behind a circuit breaker and cached fallbacks
  • Returns, refunds and relisting follow one workflow, and a refund cannot exceed 1.5× the order

Kick Avenue Marketplace integration · 2 / 2

Built to fail safely

My role

Designed and built both integrations end to end: API clients, signing, sync engine, order ingestion, CMS handover, and the technical reference the on-call team uses.

Design decisions
  • Twin services, no shared state. Shopee item/model and TikTok product/SKU are mirrored but isolated, so one channel's outage never blocks the other
  • Write guards and rate-limit backoff that honour Retry-After headers
  • Adopt before create: existing remote listings (even Anchanto-era ones) are claimed, never duplicated
  • Idempotent shipping: "already shipped" counts as success, so retries are safe

Kick Avenue Payments

Carving checkout out of the monolith in Go

Under Development

Checkout is where money moves and where bugs hurt most. I'm moving it into a small Go service with explicit offer states, so every payment outcome, late or out of order, lands in a defined state. Checkout is the first slice of a strangler-fig move: it leaves the monolith now, and the rest of the backend follows to Go one service at a time. We estimated at least a 30% infrastructure saving from lean services instead of scaling the PHP monolith’s nodes.
